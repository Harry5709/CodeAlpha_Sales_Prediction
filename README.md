## 📌 Project Overview
Sales prediction involves forecasting the amount of a product that customers will purchase based on advertising spend across various channels. In this project, we analyze how advertising budgets spent on **TV, Radio, and Newspaper** impact overall product sales and build machine learning regression models to accurately predict future sales performance.

---

## 🔑 Key Features & Highlights
* **Exploratory Data Analysis (EDA):** Analyzed feature distributions, computed correlation matrices, and created scatter plots to evaluate linear relationships with sales.
* **Feature Engineering & Selection:** Isolated key predictor variables (TV, Radio, Newspaper advertising channels).
* **Machine Learning Modeling:** Built and evaluated **Linear Regression** (and optional ensemble models like Random Forest Regressor).
* **Model Evaluation:** Evaluated predictive accuracy using **Mean Absolute Error (MAE)**, **Mean Squared Error (MSE)**, **Root Mean Squared Error (RMSE)**, and **R² Score**.

---

## 🛠️ Tech Stack & Dependencies
* **Language:** Python
* **Data Processing:** `pandas`, `numpy`
* **Data Visualization:** `matplotlib`, `seaborn`
* **Machine Learning:** `scikit-learn` (`LinearRegression`, `train_test_split`, `metrics`)
